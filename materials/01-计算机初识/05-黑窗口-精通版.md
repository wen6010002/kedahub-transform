# 黑窗口 · 精通版

计算机初识 · 第 5 站

时间：1 小时到 1 个半小时。其中读 20 分钟，动手 40 分钟，留 20 分钟给自己卡住和试错。
做完你会有一个：整整齐齐的下载文件夹。

---

## 第一步：装好要用的终端

**Windows 先装 Git Bash。**

这一站和后面几站用的命令（`mkdir -p`、`grep`、`cat` 这些）在 Windows 自带的「命令提示符」和 PowerShell 里用不了，会报错。装一个 Git Bash，就有一套和 Mac 一样的命令行环境，后面所有资料都能直接照着做。

装法：

1. 打开浏览器搜「git 下载」，进官网
2. 下载 Windows 版，双击安装
3. 一路点 Next 用默认选项。只有一处要注意：问你默认编辑器选什么的时候，选记事本或者 VS Code，别选 Vim，新手不知道怎么退出
4. 装完在开始菜单里搜 `Git Bash`，打开它

还有一个更快的打开方式：在任意文件夹里点右键，菜单里有「Open Git Bash here」，会在那个文件夹里直接打开。

**Mac 不用装。** 按 Command 加空格，输入「终端」，回车。

### 装好了是什么样

打开之后你会看到一个窗口，里面有一行字，末尾有个光标一闪一闪。Windows 上大概长这样：

```
zhangsan@LAPTOP-ABC MINGW64 ~
```

Mac 上大概长这样：

```
zhangsan@MacBook-Pro ~ %
```

两边长得不一样，但结构是一样的：`zhangsan` 是你的用户名，中间是电脑的名字，最后的 `~` 表示你现在站在「家目录」里。末尾那个 `$` 或者 `%` 是提示符，意思是「我准备好了，你说吧」。

敲一行验证一下：

```
pwd
```

它会回你一个路径。Windows 上大概是 `/c/Users/zhangsan`，Mac 上大概是 `/Users/zhangsan`。看到路径就说明对了。

Windows 上如果提示「不是内部或外部命令」，说明你打开的是系统的命令提示符，不是 Git Bash，回去重新打开。

试着敲几个字符，再按回车。它会认真执行一下，然后告诉你找不到这个命令。这很正常，因为它真的在按你说的去找。这个窗口不会猜你的意思，也不会替你决定。你打错一个字，它就照着错的去做。

这就是它和鼠标最大的区别。鼠标帮你想，帮你确认，帮你兜底。这里不兜底，所以一开始会有点慌。

## 你在哪

敲这一行：

```
pwd
```

它会回你：

```
/Users/zhangsan
```

`pwd` 是 print working directory 的缩写，意思是「把我现在所在的目录打印出来」。这三个字母是你迷路时的救命稻草，忘了自己在哪就敲它。

目录就是文件夹。电脑里所有东西都放在一棵树上的某个位置，`/` 是树根。你刚才看到的 `/Users/zhangsan` 就是从树根一路走下来的一条路径，读作「根目录下的 Users，Users 下的 zhangsan」。

Mac 上你的家目录在 `/Users/你的用户名`，Linux 上在 `/home/你的用户名`。`~` 是它的简写，跟打全了是一回事。

## 先看看这棵树

```
ls
```

`ls` 是 list，列出当前目录里的东西。你会看到桌面、下载、文档这些熟悉的文件夹。

再加一个参数看看：

```
ls -l
```

输出变成这样：

```
drwxr-xr-x   5 zhangsan  staff   160  9月 10 14:22 Desktop
drwxr-xr-x  12 zhangsan  staff   384  9月 14 09:03 Downloads
-rw-r--r--   1 zhangsan  staff  1024  9月 12 20:11 笔记.txt
```

每行开头那个字母是类型，`d` 表示这是个目录，`-` 表示这是个普通文件。中间那串 `rwxr-xr-x` 是权限，这一站先不用管，第 3 站会讲。再往后是修改时间。

再加一个参数：

```
ls -la
```

这次多出来一堆以 `.` 开头的文件，比如 `.zshrc`、`.gitconfig`。这些是隐藏文件，`-a` 是 all，把隐藏的也列出来。平时不显示是因为它们大多是配置，不需要你天天看见。

参数可以连起来写，`ls -la` 和 `ls -l -a` 效果一样。

## 走进去，再走出来

```
cd Downloads
```

`cd` 是 change directory。敲完再敲一次 `pwd`，路径变成 `/Users/zhangsan/Downloads`。你走进去了。

往回退一级：

```
cd ..
```

`..` 代表上一级目录。再往上退两级就是 `cd ../..`。

回自己家：

```
cd ~
```

或者直接敲 `cd`，不带参数，效果一样。

还有一个很好用的：

```
cd -
```

它会跳回你上一次待过的目录。在两个文件夹之间来回切换的时候特别省事。

## 建东西和搬东西

先在家目录里建一个可以随便折腾的地方：

```
mkdir 练手
cd 练手
```

`mkdir` 是 make directory。敲完 `ls` 确认一下，「练手」应该出现在列表里。

在里面建三个空文件：

```
touch 一号.txt 二号.txt 三号.txt
```

`touch` 创建一个空文件。一次可以建好几个，用空格隔开。

给其中一个改个名字：

```
mv 一号.txt 第一个文件.txt
```

`mv` 是 move，它同时负责「移动」和「改名」两件事。把文件从一个位置挪到另一个位置是移动，把文件从 `a.txt` 挪到 `b.txt` 是改名，对它来说是同一件事。

复制一个：

```
cp 二号.txt 二号备份.txt
```

`cp` 是 copy。复制目录的时候要加 `-r`，表示把里面所有东西一起带上：

```
cp -r 某个目录 新位置
```

删除：

```
rm 三号.txt
```

`rm` 是 remove。这条命令不进回收站，删了就是删了。删目录要加 `-r`，而 `rm -rf` 这个组合是出了名的危险，`-f` 表示「别问了直接删」，敲错一个空格可能就把整个项目删光。这一站的练习用不到它，先别碰。

## 命令的格式其实只有一种

回头看一遍你敲过的：

```
ls -la
cd Downloads
mkdir 练手
mv 一号.txt 第一个文件.txt
```

格式是一样的：程序名，空格，参数。参数之间也用空格隔开。

`-la` 这种带横杠的叫做选项，`Downloads` 这种叫做参数值。有些选项可以简写成 `-l`，也可以写成 `--long`，两种写法指的是同一件事。具体某个命令有哪些选项，你不用背，敲这个就行：

```
ls --help
```

它会把这个命令的所有用法列出来。看不懂英文没关系，看格式，找到你要的那个功能。

## 三个能救命的小习惯

**Tab 键补全。** 打文件名打一半，按一下 Tab，它帮你补全。按了没反应说明你打错了，或者有好几个文件都是这个开头。这个习惯能省掉你一半的打字量，还能让你少犯一半的拼写错误。

**上箭头翻历史。** 敲过的命令都在里面，按上箭头一条条翻出来，改一改就能再跑一次，不用重新打。

**Ctrl 加 C 中断。** 命令跑了半天没反应，或者你想停下它，按 Ctrl 加 C。这不是关窗口，只是打断当前这条命令。

## 现在来干正事

打开你的下载文件夹，用鼠标看一眼里面有多少东西。大概率是这样：一堆 PDF、几张截图、几个 `.dmg` 或者 `.exe` 安装包、几个压缩包、还有一些名字已经看不懂的文件。

鼠标整理这种东西，是点几百下、花二十分钟、还容易点错的活。下面用命令行做一遍。

先看看到底有多少：

```
ls ~/Downloads | wc -l
```

这里的竖线叫做管道，意思是「把左边命令的输出，交给右边命令去数」。`wc -l` 是数行数。你现在不用理解管道，第 6 站会专门讲。

然后建几个分类文件夹：

```
mkdir -p ~/Downloads/{图片,文档,压缩包,安装包,其他}
```

花括号展开的意思是「这几个名字各来一个」。`-p` 表示如果上一级目录不存在就一起建。

接着搬文件：

```
mv ~/Downloads/截图1.png ~/Downloads/图片/
```

打文件名的时候用 Tab 补全，`~/Down` 按一下 Tab 就补成 `~/Downloads/` 了。

一个一个搬，搬十几个之后你会开始烦。这种烦躁感是好事，先记住它，第 7 站会告诉你怎么办。

搬完看一眼结果：

```
ls ~/Downloads
```

## 卡住了看这里

**提示 `command not found`。** 命令拼错了，或者你系统里没有这个程序。先检查拼写，再用 Tab 补全试试。补全不出来，说明确实没这个东西。

**提示 `No such file or directory`。** 路径写错了，或者文件名大小写不对。敲 `ls` 看一眼真实的名字。Linux 和 Mac 都区分大小写，`Downloads` 和 `downloads` 是两个完全不同的东西，这一点和 Windows 不一样。

**路径里有空格，命令报错。** 空格在命令行里是分隔符，它会把一个名字切成两个。给路径加引号就行：`cd "my folder"`。更省事的办法是用 Tab 补全，它会自动帮你处理好。

**`cd` 完不知道自己在哪了。** 敲 `pwd`。以后养成习惯，进一个目录就顺手看一眼提示符。

**`rm` 删错了东西。** 这一站找不回来。练习阶段尽量只用 `mv` 和 `cp`，需要「删」的时候先把文件移到别的地方去。

**中文文件名显示成乱码。** Git Bash 里一般不会。如果遇到，多半是文件本身的编码问题，不是终端的问题。

**提示 `Permission denied`。** 你在改系统目录里的东西。换个地方。不要用 `sudo` 硬来，那是在给自己挖坑。

## 走完之后

站起来走两分钟，然后回答自己一个问题：刚才那一个多小时里，哪一段让你忘了看时间？

如果你在敲 `cd` 进去、`ls` 出来、`mkdir` 建文件夹的时候觉得顺手，甚至开始想把桌面也整理一遍，那说明你对「直接指挥机器」这件事有感觉。后端开发、运维、测试这三个岗位，每天的工作就是在这个窗口里完成的。

如果你从头到尾都在想「为什么不用鼠标」，那也很正常。这不说明你学不会，只说明你的入口应该在别的地方。第 2 模块的网页、第 3 模块的 AI 应用，都能立刻看到做出来的东西，可能更对你路子。

这一站真正的收获只有一个：你已经知道怎么让电脑做一件具体的事，并且知道出了错去哪里看。后面每一站都会用到它。
