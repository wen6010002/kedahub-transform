# 电脑是怎么工作的 · 探索版

计算机初识 · 第 1 站

时间：45 分钟左右。读 30 分钟，自己看 15 分钟。

## 按下开机键之后的十几秒

你按一下开机键，屏幕黑着，过几秒跳出一个标志，再过几秒进了桌面。

这十几秒里，电脑做了几百件事。你现在不需要知道全部，只要认识三样东西，就能解释你平时遇到的大部分问题。

这三样东西是：CPU、内存、硬盘。

它们的名字你肯定听过，买电脑的时候商家会念一堆参数，什么 i5、16G、512G。这一站就讲清楚这三个数字各自是什么，以及为什么一个卡一个不卡。

## 硬盘：东西存在这儿

硬盘是你电脑里最大的那个仓库。

你的照片、文档、游戏、下载的电影，全都躺在硬盘上。**关掉电脑，它们还在**，因为硬盘是一种断电也不会忘的存储。

硬盘的特点是：**存得多，但慢。**

慢到什么程度？如果 CPU 做一次计算需要一秒钟，那从硬盘读一个文件大概需要几个月。这个比喻是夸张的，但量级差不多。CPU 太快了，硬盘根本跟不上。

所以有了第二样东西。

## 内存：东西正在这儿用

内存是硬盘和 CPU 之间的中转站。

你打开一个软件，电脑先把它的内容从硬盘搬到内存里，然后 CPU 从内存里读。因为内存比硬盘快几十倍，CPU 才不用干等着。

内存的特点是：**快，但小，而且一断电就忘。**

你写 Word 写了半小时没保存，突然停电，那半小时就没了。因为那半小时的内容一直在内存里，还没写回硬盘。内存一断电，全忘光。

这就是为什么软件都会提醒你「保存」：保存这个动作，就是把内存里的东西写进硬盘。

**硬盘管「记住」，内存管「正在用」。** 记住这句话，电脑卡了你会先想到它。

## CPU：干活的

CPU 是电脑里那个真正在算东西的部件。

你点一下鼠标、敲一个键、播放一段视频，背后都是 CPU 在执行一串指令。它每秒能执行几十亿次，是整台电脑里最快的部件。

CPU 有两个关键指标：

**核心数**，就是它能同时干几件事。四核就是四个工人，八核就是八个工人。

**频率**，就是每个工人干活的速度。

现在买电脑看到的 i5、i7、R7 这些，是型号档次。同一代里，数字大的通常核多、频率高。

## 一个真实的场景

你在写一份文档，同时开着浏览器查资料，还挂着微信。

一开始很流畅。半小时后，你开了十几个网页标签，文档也从一页变成了十页。这时候切窗口开始卡，打字有延迟，鼠标转圈。

打开任务管理器一看，内存用了 90%。

**原因很清楚：内存不够了。**

电脑现在同时开着浏览器、Word、微信，它们都要占内存。内存装不下了，系统只好把一部分内容先挪回硬盘，等要用的时候再搬回来。硬盘比内存慢几十倍，所以卡。

解决办法有两个。关掉几个标签页，内存立刻降下来。或者加一根内存条。

这个场景里最值得记住的是：**卡的原因通常是内存不够，跟 CPU 关系不大。** CPU 大部分时间其实很闲。

## 它的边界

**这套「三样东西」的说法解释不了所有事。** 它是个简化模型，用来理解日常现象足够了，但真实情况复杂得多。显卡、主板、散热、系统调度都在起作用。

**内存大不等于不卡。** 如果软件本身写得烂，或者你在跑一个吃 CPU 的任务（比如压缩一个几 G 的文件），加内存没用。

**硬盘也分好坏。** 机械硬盘和固态硬盘的读写速度差十倍以上。同一个配置，一个用机械硬盘一个用固态，开机速度能差一分钟。这个差别比 CPU 型号的差别明显得多。

**「电脑慢」是个模糊的说法。** 开机慢、打开软件慢、玩游戏卡、导出视频慢，是四种不同的问题，对应的硬件不一样。

## 电脑卡了，怎么查
**电脑卡了，先开任务管理器看一眼。** Windows 按 Ctrl 加 Shift 加 Esc，Mac 按 Command 加空格搜「活动监视器」。看两栏：内存用了百分之多少，CPU 用了百分之多少。

内存到 90% 以上，就是内存不够，关掉一些程序。

内存很低但 CPU 到 100%，说明有程序在死算东西。找到那个占 CPU 最高的进程，看看是不是该关掉它。

两样都不高但还是卡，可能是硬盘在满负荷读写，或者显卡的问题。

**买电脑看配置，按用途看。** 只是写文档、上网课，什么配置都够，别为参数多花钱。要剪视频、跑 AI 模型，内存和显卡是关键，CPU 反而次要。要打游戏，显卡第一。

**清空间和加内存是两件事。** 硬盘满了会提示你清理，加内存解决的是「同时开太多程序就卡」。别搞混。

**让 AI 帮你判断的时候，把现象说具体。** 说「电脑卡」它只能猜。说「开了五个浏览器标签和 Word 就卡，任务管理器显示内存 92%，CPU 20%」，它就能给出准确建议。

## 自己试一下

这一站不用装东西，用系统自带的功能看就行。

### 看一眼你的 CPU 和内存

**Windows**：右键点「此电脑」，选「属性」。会看到处理器型号和安装的内存大小。

**Mac**：左上角苹果标志，选「关于本机」。会看到芯片型号和内存大小。

记下这两个数字。你以后买电脑、看别人的配置，都是在比这两个。

### 看内存被用掉是什么样

打开任务管理器（Windows 按 Ctrl 加 Shift 加 Esc；Mac 用活动监视器），找到「内存」那一栏，记下现在的使用率。

现在打开浏览器，随便开十个标签页。

再看一眼那个数字，涨了多少？

把浏览器关掉，再看一眼，它降回去了。

**这就是内存的工作方式：用的时候占住，不用的时候还回来。** 你现在亲眼看到它了。

### 看硬盘还剩多少

**Windows**：打开「此电脑」，看 C 盘那条进度条。

**Mac**：苹果标志，选「关于本机」，点「储存空间」。

如果剩余空间不到 10%，你的电脑会开始变慢，因为系统需要空间来做临时周转。

### 看硬盘上的东西有多大

打开终端（Windows 用 Git Bash，Mac 用终端。还没装的看第 5 站），敲：

```
du -sh ~
```

它会算出你个人文件夹一共占了多少空间。输出大概是这样：

```
12G	/Users/zhangsan
```

想知道每个文件夹分别占多少，敲：

```
du -sh ~/* | sort -h | tail -5
```

它会列出占空间最大的五个文件夹。

## 想再往下看

想更仔细地看自己的电脑在干什么，Mac 上有一个叫「活动监视器」的东西（Windows 是「资源监视器」），能看每一个程序占了多少内存和 CPU。玩一玩，你会对「我的电脑在忙什么」有具体的印象。

对「为什么硬盘比内存慢那么多」好奇的话，可以搜「机械硬盘 固态硬盘 原理」，看看这两种东西物理上有什么不同。这个话题会牵扯到第 2 站的二进制，一起看更顺。
