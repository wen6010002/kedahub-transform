## 做网页是不是一定要有服务器

上一站讲了，一个网页从打开到显示，要经过服务器、数据库好几个环节。

那如果我不会后端，是不是就什么都做不了？

不是。**前端自己就能做出很多东西，而且有些东西做出来跟装个软件差不多。**

这一站全是例子，看完你会对「只写前端能做到什么程度」有个具体的印象。

## 六件只靠前端就能做出来的东西

### 一、计算器

输入两个数，选一个运算，出结果。整个逻辑在浏览器里跑，不联网也能用。

### 二、待办清单

加一条、划掉一条、删一条。关掉浏览器再打开，清单还在。

**为什么还在？** 因为浏览器提供了本地存储，能把数据存在你自己的电脑上。不需要服务器。

### 三、番茄钟

设 25 分钟，倒计时，时间到了响一声。跑在浏览器里，手机上打开也能用。

### 四、数据图表

你有一份数据，想画成柱状图或者折线图。有一批现成的图表库，你把数据喂进去，它就把图渲染出来。整个过程不需要后端。

### 五、在线画板

鼠标按住拖动就画线，能换颜色、能撤销。所有笔画都记在浏览器里。

### 六、小游戏

贪吃蛇、2048、扫雷，这类小游戏完全跑在浏览器里，不需要联网。

## 为什么这些不用后端

因为它们的共同点是：**数据只属于你自己，不需要分享给别人。**

待办清单只给一个人看，番茄钟只给一个人用，画板上的东西也不打算发给别人。这些数据存在你自己的浏览器里就够了。

后端解决的是另一类问题：**数据要让别人看见、要让多个人共用、要保证不丢。**

你的待办清单不需要别人看见，所以不用后端。但如果你要做的是「宿舍四个人共用一个购物清单，谁改了别人都能看见」，那就必须要后端了。

**判断方法很简单**：这份数据除了我，还有别人要看吗？有，就要后端。没有，前端自己就够了。

## 一个真实的场景

有个学生想给班里做一个「期末复习倒计时」的网页。

他的第一反应是「我不会后端，做不了」。后来他想了想，这个网页的需求是：显示距离考试还有多少天，列出几门课的复习进度。

这些数据谁需要看？只有他自己。别人打开这个网页，看到的是别人的进度，跟自己没关系。

所以他做了一个纯前端的版本。数据存在浏览器本地，他在自己电脑上更新进度，关掉再打开还在。整个网页就是一个 HTML 文件，双击就能用。

**他花了一个周末做完，没有服务器、没有数据库、没有花一分钱。**

如果他一开始就按「必须要有后端」的思路去做，得先租服务器、学后端语言、配数据库，一个月都做不完，而且做出来的东西跟纯前端版本没有区别。

**先想清楚需求，再决定用什么。** 这句话值钱，记着。

## 它的边界

**数据只存在这台电脑这个浏览器里。** 换台电脑打开，数据就没了。清空浏览器数据，也没了。本地存储本来就是这样，不算出问题。

**数据不能分享。** 你的清单只有你能看见。想让别人看到，必须传出去，而传出去就需要后端。

**别人看不到你做了什么。** 你把网页文件发给同学，他打开看到的是他自己浏览器里的数据，不是你的。

**有些东西前端做不了。** 用户注册登录（要验证身份）、在线支付（要保证安全）、发消息给别人（要有个中转站）、内容搜索（要有个地方存全部内容）。

**纯前端的东西容易被看到。** 按 F12 就能看到你的全部代码，包括你写在里面的数据。所以不要把私密的东西放在前端。

## 要不要后端，先问三个问题
**判断一个想法要不要后端，问三个问题。**

这份数据只有我看吗？有没有别人也要看？换个设备打开，我需要看到一样的东西吗？

三个问题的答案都是「没有」或者「不需要」，那就是纯前端能做的。

**让 AI 帮你做纯前端的东西，说明白一件事**：这个工具只有我自己用，数据存本地就行，不用服务器。

不说这一句，AI 可能会给你一套需要后端的方案，你还得去配环境。

**几个能照做的办法**：

想做一个自己用的小工具，直接把需求描述给 AI：「做一个番茄钟的网页，纯前端，数据存 localStorage，一个 HTML 文件就行」。

做完之后把文件保存成 `.html`，双击就能用，也可以发给同学。

想改改别人的小工具，把代码发给 AI，说清楚你想改哪里。

## 自己试一下

这一站不用装东西，用浏览器就能看见「数据留在本地」是什么样。

### 让浏览器记住一件事

随便打开一个网页，按 F12 打开开发者工具。

切到「Console」面板（中文版叫「控制台」）。这是一个能让你直接敲代码的地方，敲一行回车，它立刻执行。

在光标处敲这一行，回车：

```javascript
localStorage.setItem('我的笔记', '今天学了一个新东西')
```

没有输出，就是成功了。

现在敲这一行：

```javascript
localStorage.getItem('我的笔记')
```

它会回你 `今天学了一个新东西`。

### 刷新页面，看它还在不在

按 F5 刷新页面。

再敲一次：

```javascript
localStorage.getItem('我的笔记')
```

**那句话还在。**

你没有登录任何账号，没有连任何服务器，这句话就存在你这台电脑的这个浏览器里。

### 想想刚才发生了什么

你刚才做的事，就是那些「不用登录也能记住设置」的网站干的事。

比如你调了一次网页的深色模式，下次打开还是深色。它没法知道你是谁（你没登录），但它知道**这个浏览器**之前调过什么。

这些数据存在你自己电脑上的一个地方，跟着浏览器走，不跟着你走。所以你换个浏览器打开同一个网站，设置就没了。

### 看一眼所有存在本地的数据

```javascript
Object.keys(localStorage)
```

它会列出这个网站存在你本地的东西有哪些。你会看到一些看不懂的名字，那都是网站存下来的。

前端能自己存数据、自己做计算、自己画界面。判断要不要后端的标准是「这份数据除了我还有别人要看吗」。

## 几个常见的误解

**「不联网就什么都做不了。」** 纯前端的东西离线也能用。你把一个网页文件存在电脑上，双击打开，断网了照样跑。

**「清空浏览器数据不要紧。」** 清掉之后，所有存在本地的数据一起没：你的待办清单、你的设置、你调过的深色模式。这些数据没有备份，因为没有服务器存过它们。

**「本地存的东西别人看不到。」** 你自己按 F12 就能在 Console 里把所有本地数据列出来。所以别把私密的东西存在浏览器里，尤其别在公共电脑上存。

**「纯前端的东西不专业。」** 判断标准是需求，不是技术含量。一个只用你自己看的工具，纯前端版本往往比带后端的版本更合适：不用服务器、不用花钱、不怕服务器挂。
