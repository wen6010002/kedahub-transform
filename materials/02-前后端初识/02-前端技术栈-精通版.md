# 前端技术栈 · 精通版

前后端初识 · 第 2 站

时间：2 小时到 2 个半小时
做完你会有一个：一个能发给同学看的个人主页

---

## 第一步：装一个写代码的工具

浏览器你已经有了，不用装。要装的是一个写代码的编辑器。

用记事本也能写网页，但它不会帮你标出写错的地方，也不会自动缩进，写到一百行你会很痛苦。

**Windows 和 Mac 都装 VS Code**

1. 打开浏览器，搜「VS Code 下载」，第一个就是官网
2. 下载对应系统的版本，双击安装
3. 装完打开它，界面上会问你要不要装中文语言包，建议装上

装完之后，在终端里敲 `code --version`，看到版本号就说明好了。以后想用 VS Code 打开某个文件夹，敲 `code 文件夹名` 就行。

**再准备一个浏览器。** 用系统自带的也行，但推荐装 Chrome，因为它的开发者工具最好用。搜「Chrome 下载」装上。

## 第二步：第一个网页

建一个专门放网页的文件夹：

```
cd ~
mkdir 我的网站
cd 我的网站
```

用 VS Code 打开这个文件夹：

```
code .
```

那个 `.` 表示「当前文件夹」。

在 VS Code 左边找到「新建文件」的图标，建一个文件，名字叫 `index.html`。

**文件名必须是 `index.html`。** 这是网页的默认入口，服务器和浏览器找不到具体文件的时候都会先找它。

现在把下面这些内容敲进去：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的主页</title>
</head>
<body>
  <h1>你好，我是张三</h1>
  <p>这是我写的第一个网页。</p>
</body>
</html>
```

存盘（Ctrl 加 S，Mac 上是 Command 加 S）。

回到文件夹，双击 `index.html`。浏览器会打开它，页面上出现两行字。

**这就是一个网页。** 它现在很朴素，但已经是一个真的网页了。

### 刚才那几行分别是什么

`<!DOCTYPE html>` 是告诉浏览器「这是一份 HTML 文档」。

`<html lang="zh-CN">` 是根标签，`lang="zh-CN"` 告诉浏览器这页是中文的。

`<head>` 里面放的是给浏览器看的信息，不显示在页面上。`<meta charset="UTF-8">` 指定编码，**这一行必须写，不写中文会乱码**。`<title>` 是浏览器标签页上显示的字。

`<body>` 里面才是显示给用户看的内容。

`<h1>` 是一级标题，`<p>` 是一段话。

## 第三步：把内容搭出来

HTML 的标签有几十个，常用的就十来个。认识一下：

```html
<h1>最大的标题</h1>
<h2>第二级标题</h2>
<p>一段话。</p>
<a href="https://example.com">一个链接</a>
<img src="照片.jpg" alt="照片说明">
<ul>
  <li>列表第一项</li>
  <li>列表第二项</li>
</ul>
<div>一个盒子，用来把东西装在一起</div>
<span>一小段文字，用来单独给它加样式</span>
```

`<div>` 和 `<span>` 本身不带任何意思，就是两个盒子。它们的作用是把内容分组，方便后面加样式。

现在把 `index.html` 改成这样：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的主页</title>
</head>
<body>
  <h1>张三</h1>
  <p>计算机专业 · 大一</p>

  <h2>我在学什么</h2>
  <ul>
    <li>HTML 和 CSS</li>
    <li>JavaScript</li>
    <li>一点点 Python</li>
  </ul>

  <h2>找到我</h2>
  <p><a href="https://github.com">我的 GitHub</a></p>
</body>
</html>
```

存盘，回到浏览器按 F5 刷新。内容变了。

**记住这个循环：改代码 → 存盘 → 刷新浏览器看结果。** 你后面会重复几百遍。

## 第四步：给它加样式

现在页面能看，但很丑。加样式要用 CSS。

CSS 写在 `<head>` 里面的 `<style>` 标签里。把 `index.html` 改成这样：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的主页</title>
  <style>
    body {
      font-family: "Microsoft YaHei", sans-serif;
      max-width: 640px;
      margin: 60px auto;
      padding: 0 20px;
      line-height: 1.8;
      color: #333;
    }
    h1 {
      font-size: 30px;
      margin-bottom: 4px;
    }
    h2 {
      font-size: 18px;
      margin-top: 36px;
    }
    a {
      color: #ff6b4a;
    }
  </style>
</head>
<body>
  <h1>张三</h1>
  <p>计算机专业 · 大一</p>

  <h2>我在学什么</h2>
  <ul>
    <li>HTML 和 CSS</li>
    <li>JavaScript</li>
    <li>一点点 Python</li>
  </ul>

  <h2>找到我</h2>
  <p><a href="https://github.com">我的 GitHub</a></p>
</body>
</html>
```

刷新。整页的字体变了，行距松了，内容居中了，链接变成橙色了。

### CSS 的写法

每一条 CSS 都是这个格式：

```
选择器 {
  属性: 值;
}
```

选择器决定「改哪些东西」。`body` 是改整个页面，`h1` 是改所有一级标题，`a` 是改所有链接。

常用的几个属性：

```
color              文字颜色
background-color   背景颜色
font-size          字号
font-weight        字重，bold 是加粗
margin             外边距，和别人的距离
padding            内边距，内容和自己边框的距离
border-radius      圆角
text-align         文字居中还是靠左
```

上面那个 `margin: 60px auto` 是个常用写法。`60px` 是上下留 60 像素，`auto` 是左右自动，效果就是**居中**。

### 给某一块单独加样式

刚才的选择器都是按标签选的。如果你想只给某一小块加样式，就要先给它起个名字：

```html
<div class="card">
  <h2>我在学什么</h2>
  <p>HTML、CSS、JavaScript。</p>
</div>
```

`class="card"` 就是给这个 div 起了个名字叫 `card`。CSS 里用 `.card` 来选中它：

```css
.card {
  border: 1px solid #eee;
  border-radius: 12px;
  padding: 20px;
  margin-bottom: 16px;
}
```

**注意那个点。** `.card` 是「class 叫 card 的元素」，`card` 是「card 这个标签」，两个完全不同的意思。

## 第五步：让它能交互

HTML 和 CSS 只能做静态的东西。要让页面响应你的操作，得用 JavaScript。

JavaScript 写在 `<body>` 的最后面，包在 `<script>` 标签里：

```html
<script>
  var n = 0;
  var btn = document.getElementById('btn');
  var out = document.getElementById('count');

  btn.addEventListener('click', function () {
    n = n + 1;
    out.textContent = '你点了 ' + n + ' 次。';
  });
</script>
```

同时，在 body 里加上对应的元素：

```html
<div class="card">
  <h2>点一下试试</h2>
  <p id="count">你还没点过。</p>
  <button id="btn">点我</button>
</div>
```

`id="btn"` 是给这个按钮起了个独一无二的名字。`document.getElementById('btn')` 就是「找到那个 id 叫 btn 的元素」。

`addEventListener('click', ...)` 的意思是「当它被点击的时候，做后面那件事」。

`out.textContent = ...` 是「把这个元素里的文字换成新的」。

刷新页面，点几下按钮，数字会涨。

**这就是所有网页交互的骨架**：找到元素、监听事件、改变内容。你现在看到的那些复杂的网页，拆到底也是这三步，只是组合得更复杂。

## 完整的文件

把上面几步合起来，`index.html` 最终长这样：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>张三的主页</title>
  <style>
    body {
      font-family: "Microsoft YaHei", sans-serif;
      max-width: 640px;
      margin: 60px auto;
      padding: 0 20px;
      line-height: 1.8;
      color: #333;
    }
    h1 { font-size: 30px; margin-bottom: 4px; }
    .sub { color: #888; margin-bottom: 32px; }
    h2 { font-size: 18px; margin-top: 36px; }
    a { color: #ff6b4a; }
    .card {
      border: 1px solid #eee;
      border-radius: 12px;
      padding: 20px;
      margin-bottom: 16px;
    }
    button {
      background: #ff6b4a;
      color: #fff;
      border: none;
      border-radius: 8px;
      padding: 10px 20px;
      font-size: 15px;
      cursor: pointer;
    }
    button:hover { background: #ed4e2d; }
  </style>
</head>
<body>
  <h1>张三</h1>
  <div class="sub">计算机专业 · 大一</div>

  <div class="card">
    <h2>我在学什么</h2>
    <ul>
      <li>HTML 和 CSS</li>
      <li>JavaScript</li>
      <li>一点点 Python</li>
    </ul>
  </div>

  <div class="card">
    <h2>点一下试试</h2>
    <p id="count">你还没点过。</p>
    <button id="btn">点我</button>
  </div>

  <script>
    var n = 0;
    var btn = document.getElementById('btn');
    var out = document.getElementById('count');

    btn.addEventListener('click', function () {
      n = n + 1;
      out.textContent = '你点了 ' + n + ' 次。';
    });
  </script>
</body>
</html>
```

那个 `<meta name="viewport" ...>` 是给手机看的，加上之后手机上打开不会缩成一团。

## 动手任务

一、把 `index.html` 敲出来，打开看效果。不要复制，手敲一遍，敲的过程会让你记住标签长什么样。

二、改文字。把名字、专业、列表内容换成你自己的。

三、改颜色。把 `#ff6b4a` 换成你喜欢的颜色。颜色代码可以在网上搜「颜色代码表」，或者用 VS Code 里点颜色方块直接挑。

四、加一个 `.card`。再加一个卡片，写点别的内容，比如「我在玩的游戏」。

五、加一个交互。仿照按钮那个例子，做一个「换一句名言」的按钮，点一次换一句话。提示：准备一个数组存几句话，点的时候随机取一句。

六、用浏览器打开，按 F12，在手机上预览。开发者工具左上角有一个手机图标，点它就能切换成手机尺寸，看看你的页面在窄屏幕上是什么样。

## 正式产出

**一个能发给同学看的个人主页。**

要求：

- 至少三个卡片区块（比如「我是谁」「我在学什么」「找到我」）
- 有样式，不是浏览器默认的样子
- 至少一个能点的交互
- 手机上打开不乱
- 没有报错（按 F12 看 Console 面板，里面不该有红字）

做完把 `index.html` 发给同学，让他双击打开看看。

如果他打开之后样式全没了、只有光秃秃的文字，检查一下 `<style>` 标签有没有写全，或者有没有把 `</style>` 漏掉。

## 卡住了看这里

**中文显示成乱码。** `<head>` 里少了 `<meta charset="UTF-8">`，或者存盘的时候编码不是 UTF-8。VS Code 右下角能看编码，改成 UTF-8。

**改了代码，刷新没变化。** 浏览器缓存了旧版本。按 Ctrl 加 F5（Mac 上是 Command 加 Shift 加 R）强制刷新。

**样式完全不生效。** 先检查 `<style>` 标签有没有写全，再检查每条 CSS 末尾的分号有没有漏。少一个分号，后面几条都会失效。

**`document.getElementById` 返回 null。** 说明它没找到那个 id。检查三件事：元素的 `id` 拼写对不对、`<script>` 是不是放在元素后面、`id` 有没有重复。

**点击按钮没反应。** 按 F12 看 Console 面板，里面有红字的话，红字会告诉你哪一行出错。

**页面上出现了奇怪的尖括号内容。** 说明标签没闭合。`<div>` 要有对应的 `</div>`，`<p>` 要有 `</p>`。VS Code 会把没闭合的标签标红。

**手机上打开缩成一团。** 少了 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`。

## 走完之后

前端是最容易看到成果的方向。你写一行，刷新一下，立刻看到变化。这个反馈速度是别的方向给不了的。

判断自己对不对路子，问自己一个问题：刚才调样式的过程中，你有没有反复刷新、反复微调，而且不觉得烦？

如果有，那说明你能忍受前端那种「差一点点」的调试。前端大量的时间就花在这上面：调间距、试颜色、挪位置，改一下看一眼，再改一下。

如果你觉得这个过程很枯燥，更喜欢让逻辑跑通就完事，那后端可能更适合你。

## 想再往下看

上面写的都是最基础的写法。真实的项目里会用框架（React、Vue 这些），它们解决的是「页面多了以后怎么组织代码」的问题。

想看看框架长什么样，可以搜「Vue 快速上手」，跟着官网的教程做一个计数器。你会发现它把「找到元素、监听事件、改内容」这三步简化了很多。

不着急学框架也行。先把这三样基础用熟，框架半个月就能上手。
