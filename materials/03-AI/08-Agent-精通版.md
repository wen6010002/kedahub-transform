## Agent 的循环，长什么样

探索版讲过，Agent 和普通问答的区别是：**它能用工具，而且能根据工具的结果，决定下一步。**

那个「想、做、看、再想」的循环，听起来玄，其实用代码写出来，就是几个很普通的动作：

- 一个**循环**（一件一件地干）
- 一个**工具**（一个函数，干一件具体的事）
- 一个**判断**（根据结果，决定接下来干嘛）

这一站你亲手把这个循环搭出来。不用接真模型，用固定的循环和判断，把 Agent 的骨架搭清楚。搭完你就明白，那些看起来聪明的 Agent，骨架跟你这个一模一样。

## 第一次动手：一个会「查价格」的 Agent

新建一个文件夹，建文件叫 `agent.js`，敲进这些内容：

```js
function getPrice(item) {
  var prices = { '苹果': 5, '香蕉': 3, '牛奶': 8, '面包': 6 };
  return prices[item];
}

var shoppingList = ['苹果', '香蕉', '牛奶'];
var budget = 15;
var total = 0;

console.log('目标：算购物清单总价，超过 ' + budget + ' 元要提醒');
console.log('清单：' + shoppingList.join('、'));

for (var i = 0; i < shoppingList.length; i++) {
  var item = shoppingList[i];
  var price = getPrice(item);
  total = total + price;
  console.log('调工具「查价格」：' + item + ' = ' + price + ' 元');
}

if (total > budget) {
  console.log('判断：总价 ' + total + ' 元，超过预算，要提醒');
} else {
  console.log('判断：总价 ' + total + ' 元，没超预算');
}
```

存盘，终端里进到文件夹，敲：

```
node agent.js
```

你会看到：

```
目标：算购物清单总价，超过 15 元要提醒
清单：苹果、香蕉、牛奶
调工具「查价格」：苹果 = 5 元
调工具「查价格」：香蕉 = 3 元
调工具「查价格」：牛奶 = 8 元
判断：总价 16 元，超过预算，要提醒
```

**你刚才搭了一个 Agent 的骨架。** 拆开看它干了什么：

`getPrice` 是**工具**，它的职责特别单一：报一个东西的价格。

`for` 循环是 Agent 的「**一件一件干**」：清单里有三样，就调三次工具，每查一样，累加到 `total`。

最后那个 `if` 是「**根据结果做判断**」：查完发现总价 16，超过预算 15，于是输出「要提醒」。

---

## 这里和真 Agent 的差别

你可能会问：这跟真 Agent 差在哪？差在一个地方：**「思考」谁来做。**

真 Agent 里，那个「下一步该查哪个、什么时候停、查到结果怎么理解」的思考，是**模型**做的。模型看着目标和上一步的结果，决定下一步。

这个 demo 里，思考被写死了：循环的次数是固定的（三样东西查三次），判断的规则是固定的（超过 15 就提醒）。

**但骨架一模一样。** 真 Agent 就是把这个「写死的思考」，换成「模型现场想」。循环、工具、判断，这三样东西，真 Agent 一样都不少。

这也是为什么你值得亲手搭一遍：搭完你就知道，Agent 就是「循环 + 工具 + 判断」的机器，不是魔法。

## 一层一层加

### 加一个工具

现在 Agent 只会「查价格」。给它加个「查库存」的工具：

在 `getPrice` 下面加：

```js
function getStock(item) {
  var stock = { '苹果': 10, '香蕉': 0, '牛奶': 20, '面包': 5 };
  return stock[item];
}
```

然后在循环里，查价格的同时也查库存：

```js
  var stock = getStock(item);
  console.log('调工具「查库存」：' + item + ' 库存 ' + stock + ' 个');
```

再跑，你会看到 Agent 现在每查一样，调两次工具。**这就是「给 Agent 加手脚」：多一个工具，它就能多干一种活。**

### 让判断更聪明

现在只判断「超没超预算」。加一个「缺货提醒」：如果某样东西库存是 0，提醒它缺货。

在循环里加：

```js
  if (stock === 0) {
    console.log('判断：' + item + ' 缺货，要提醒');
  }
```

再跑，你会看到「香蕉 库存 0 个」，下面跟着「判断：香蕉 缺货，要提醒」。

**你现在做的事，就是「给 Agent 加规则」：它查到结果之后，能做的判断更多了。** 真 Agent 里，这些判断是模型临时想的，但「根据结果做反应」这个模式，一样。

## 动手任务

一、照上面的代码跑一遍，看到三个「调工具」和最后的判断。

二、给 Agent 加一个「查优惠」的工具（比如苹果打八折），让总价计算把优惠算进去。

三、让判断更细：总价超过预算时，列出「是哪些东西导致超的」。

四、把清单换成你自己的一串东西，预算换成你的，看 Agent 怎么处理。

五、故意传一个 `getPrice` 里没有的东西（比如「西瓜」），看会发生什么。报错之后，想想真 Agent 会怎么处理这种「查不到」的情况。

## 正式产出

**一个带至少两个工具、能做两种判断的 Agent 骨架。**

要求：

- 至少两个工具函数
- 用循环一件件处理
- 根据结果至少做两种不同的判断
- 你能说清「真 Agent 和这个 demo 差在哪」

## 卡住了看这里

**提示 `SyntaxError` 或者 `Unexpected token`。** 多半是中文符号混进了代码。检查引号、括号、逗号，都要英文的。特别是 `{ }` 和 `（ ）`、`，` 和 `,`。

**跑出来是乱码。** 你的文件编码不对。用 VS Code 存文件时，右下角确认编码是 UTF-8。

**传了个不存在的商品，程序崩了。** `getPrice` 里没有那个键，返回 `undefined`，后面一算就报错。真 Agent 会处理这种情况（查不到就说查不到）。你可以试试自己加一个判断：查到 `undefined` 就提示「查不到」。

**改了代码，跑的还是旧的。** 存盘了没有？存完再 `node agent.js` 跑一次。

## 走完之后

你现在知道 Agent 的底细了：它不神秘，就是「循环 + 工具 + 判断」，聪明的那部分（思考）由模型补上。

这个认识很值钱。以后再看到什么「智能体」「Agent 平台」，你不会被唬住，你会知道它背后就是这么个骨架，只是工具更多、判断更聪明。

判断自己对不对路子，看一个感觉：当你把「查价格、查库存、做判断」这些一步步串起来，有没有一种「我在搭一个会干活的小机器」的爽感。有的话，AI 应用开发这条线适合你。
