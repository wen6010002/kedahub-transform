## 你每次都要重新想一遍怎么问

你有没有发现，同样一件事，你每次都要重新组织语言？

比如你每周都要写一份周报。这周想半天怎么写，下周又想半天。每次都是从零开始想「怎么写」。

其实「怎么写周报」这件事，你想清楚一次就够了。把这一次想清楚的东西记下来，以后每次照着填，就再也不用从头想。

这份「记下来的东西」，就是**提示词模板**。这一站教你怎么做一套自己的模板。

---

## 一个好提示词，有六块

看一条结构完整的提示词长什么样：

```
你是一个大学社团的宣传部长，负责写招新文案。

背景：我们社团叫「光影社」，是一个摄影社团，面向大一新生招新。

任务：写一篇招新文案。

格式：分四段，第一段讲我们是谁，第二段讲能学到什么，
第三段讲零基础也能来，第四段号召报名。总共 300 字以内。

例子：参考这种活泼的语气：「不会拍照？没关系，我们教你。
没有相机？手机也能玩。只要你想留住生活里的光，就来光影社。」

约束：不要用「高大上」这种空词，不要写成广告腔。
```

这条提示词，可以拆成六块，块块都有用：

**角色。** 开头那句「你是一个……」告诉模型，用什么样的身份和语气来答。写周报就说「你是一个大学生」，写文案就说「你是一个文案」。

**背景。** 把来龙去脉说清，模型才知道该往哪个方向接。漏了背景，它就容易说得太泛。

**任务。** 一句话说清到底要它干什么。这是六块里唯一不能省的一块。

**格式。** 说清输出的样子：几段、几个点、多少字、要不要表格。格式给得死，出来的东西才整齐。

**例子。** 给一两条你想要的感觉。第 4 站探索版讲过，例子比形容词管用。

**约束。** 说清「不要什么」。不要空话、不要广告腔、不要超过多少字。把红线划出来，模型才不会跑偏。

**这六块不是每条提示词都要写全。** 简单的事，任务 + 格式就够了。复杂的事，六块都给上。但你要知道有这六块，缺哪块的时候能反应过来。

## 第一次动手：从一句话，加到六块

拿一个真实的事练手。假设你要让模型帮你写「课程总结」。

### 第一步，最简陋的问法

发这一句：

```
帮我写一份课程总结
```

它会给你一段泛泛的话，可能还要反过来问你「什么课、写给谁」。

### 第二步，补上背景和任务

改成：

```
我是大一学生，刚上完《计算机导论》这门课。
帮我写一份这门课的学习总结。
```

这次它能写了，但内容还是有点空。

### 第三步，补上格式

改成：

```
我是大一学生，刚上完《计算机导论》这门课。
帮我写一份这门课的学习总结。

格式：分三个部分，第一部分写我学到了什么（至少 4 条，每条 20 字以内），
第二部分写我遇到的最大困难是什么，第三部分写下学期的打算。
总共 500 字以内，用小标题分节。
```

这次出来的东西，结构就整齐了，直接能交。

**你刚才做的，就是「从一句话，补成完整模板」的过程。** 每补一块，结果就好一点。这就是六块的作用。

---

## 一层一层加：把它变成能反复用的模板

上面的提示词有个问题：它写死了「《计算机导论》」，只能这一次用。

把它改成「填空的模板」，就能每周、每门课反复用：

```
我是大一学生，刚上完《____》这门课。
帮我写一份这门课的学习总结。

格式：分三个部分，第一部分写我学到了什么（至少 4 条，每条 20 字以内），
第二部分写我遇到的最大困难是什么，第三部分写下学期的打算。
总共 500 字以内，用小标题分节。
```

以后要写哪门课的总结，就把课名填进那个空里。

**这就是模板的价值：一次想清楚，以后只填空。**

---

## 再上一层：做一个「专属模板库」

你会遇到很多「反复要写」的事：周报、课程总结、社团文案、活动通知、请假条……

给每一件，做一个模板，存下来。存哪都行：一个记事本文件、一个备忘录、一个文档。

下面是三个现成的，你可以直接用，也可以照着改成自己的：

### 模板一：周报

```
我是大学生，在____（社团/部门）做____。
帮我写本周周报。

格式：分「本周做了什么」「下周打算做什么」「遇到了什么问题」三块，
每块 2 到 3 条，每条一句话。总共 200 字以内。语气简洁，不吹不装。
```

### 模板二：活动通知

```
帮我写一条活动通知，发在班级群。

活动：____
时间：____
地点：____
参加方式：____

要求：50 字以内，说清这四件事，语气友好，结尾提醒大家准时参加。
```

### 模板三：给老师的请假条

```
帮我写一张请假条，我是学生____，因为____，需要请假____天（从____到____）。

要求：正式一点，分三段：说明情况、说明我会补上落下的内容、表达歉意。
100 字以内。
```

## 动手任务

一、挑一件你真实要写的事（周报、总结、文案、通知都行），照「六块」写一条完整的提示词，试一次，看结果。

二、把这条提示词改成「填空模板」，换一个具体内容再试一次，确认模板能反复用。

三、再做两个模板，一共攒够三个，每个都真的试一遍。

四、把你的模板存进一个文件（记事本、备忘录、云文档都行），以后要用就复制出来填空。

## 正式产出

**一套自己的提示词模板库，至少三个，每个都试过、能用。**

要求：

- 每个模板都有明确的「填什么空」
- 每个模板都用真实内容试过一次，结果你能用
- 模板存在一个你找得到的地方
- 你能说清每个模板对应哪六块（至少任务和格式）

## 卡住了看这里

**模型给的答案很空、很泛。** 多半是背景和任务没给够。把「你是谁、要干什么、给谁看」补上再试。

**模型给的格式不对。** 你的「格式」没写清楚。把「几段、几个点、多少字」写死，别用「简洁一点」这种模糊说法。

**模型没照你的例子来。** 例子给少了，或者例子不够典型。多给一两条，或者把例子的特征点明（「照这个口语化程度」「照这个长短」）。

**模型写出来的东西你改来改去还是很别扭。** 那是「约束」没写。把你不想要的（空话、广告腔、太正式）明确列出来。

**每次问，结果都不一样。** 正常，模型每次都在重新算。所以更要靠模板固定住关键要求，减少随机性。

## 走完之后

提示词模板，说到底是「把你反复要做的沟通，一次性想清楚、固定下来」。

这件事的收益是长期的：你每攒一个模板，以后就少动一次脑子。攒多了，你写东西、查东西、整理东西的速度，会快一大截。

判断自己对不对路子，看一个感觉：当你发现「我不光会问 AI，我还知道怎么让 AI 稳定地给我好东西」，你就算入了门。剩下的是攒模板的体力活。
