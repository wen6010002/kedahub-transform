## 你想亲眼看一次「机器学会东西」

前面探索版讲过，训练是「瞎猜、看错多少、改一点」的循环。

这一站，你真的跑一次。你要训练的，是史上最简单的「能学习」的东西，叫**感知机**。它的任务特别简单：给你一个点的坐标，判断这个点在一条线的哪一边。

虽然简单，但它「学习」的机制，和那些几百亿参数的大模型，是同一套：**先瞎猜，看错多少，往对的方向改一点，重复。**

---

## 它要学什么

先搞清这个任务。

想象一张坐标纸，中间画一条斜线（对角线）。这条线把纸分成两半：线上面是一类，线下面是另一类。

我们撒 200 个点在这张纸上，每个点都知道自己是「线上」还是「线下」。这 200 个带标签的点，就是**训练数据**。

感知机要学的，就是「判断一个点在线的哪一边」这个规律。它一开始不知道这条线在哪，只能瞎猜。训练，就是让它一步步把「线」的位置猜出来。

## 第一次动手：跑起来

新建一个文件夹，建一个文件叫 `train.py`，把下面这段代码原样敲进去（或者复制）：

```python
import random
random.seed(11)

# 造 200 个点：对角线 x2 = x1 上方的记 1，下方的记 -1
def true_label(x1, x2):
    return 1 if x2 > x1 else -1

data = []
while len(data) < 200:
    x1 = random.uniform(-10, 10)
    x2 = random.uniform(-10, 10)
    y = true_label(x1, x2)
    a = sum(1 for d in data if d[2] == 1)
    b = len(data) - a
    if y == 1 and a >= 100:
        continue
    if y == -1 and b >= 100:
        continue
    data.append((x1, x2, y))

# 感知机：权重一开始全 0，等于「还没学，全部猜成 B 类」
w1, w2, b = 0.0, 0.0, 0.0

def predict(x1, x2):
    return 1 if w1*x1 + w2*x2 + b > 0 else -1

def acc():
    right = sum(1 for x1, x2, y in data if predict(x1, x2) == y)
    return right / len(data) * 100

print("第 0 轮（还没学，全部瞎猜成 B 类）：准确率 %.0f%%" % acc())

for rnd in range(1, 100):
    changed = 0
    for x1, x2, y in data:
        if predict(x1, x2) != y:
            w1 += y * x1
            w2 += y * x2
            b  += y
            changed += 1
    if rnd in (1, 2, 3, 5, 10, 20):
        print("第 %2d 轮：准确率 %.0f%%（这一轮改了 %d 个点）" % (rnd, acc(), changed))
    if changed == 0:
        print("第 %2d 轮：全部答对，训练结束" % rnd)
        break
```

存盘。回到终端，进到文件所在文件夹，敲：

```
python3 train.py
```

（Windows 敲 `python train.py`。）

你会看到类似这样的输出：

```
第 0 轮（还没学，全部瞎猜成 B 类）：准确率 50%
第  1 轮：准确率 98%（这一轮改了 20 个点）
第  2 轮：准确率 98%（这一轮改了 3 个点）
第  3 轮：准确率 96%（这一轮改了 3 个点）
第  5 轮：准确率 100%（这一轮改了 5 个点）
第 10 轮：准确率 98%（这一轮改了 2 个点）
第 14 轮：全部答对，训练结束
```

**你刚亲眼看到了「机器学会东西」。** 第 0 轮，它纯瞎猜，准确率 50%（跟抛硬币一样）。几轮之后，它摸到了规律，准确率冲上 90 多，最后稳定在 100%。

中间有个小反复（98 → 96 → 100 → 98），这是正常的。它每轮只改「分错的点」，改完这个，可能又把别的改错了。但整体趋势是往上，最后全对。**这就像人学东西，会反复，但总体在进步。**

## 看懂核心那几行

整段代码，你不用全懂。真正是「训练」的，就中间那个循环。拆开看：

```python
for x1, x2, y in data:
    if predict(x1, x2) != y:
        w1 += y * x1
        w2 += y * x2
        b  += y
```

这段在干的事：

`for ... in data`：把 200 个点，一个一个拿出来看。

`if predict(...) != y`：**猜一猜这个点是哪类，看猜对没有。** `predict` 是用当前的权重算，`y` 是真实答案，不一样就是猜错了。

`w1 += y * x1` 这一行：**猜错了，就往正确的方向挪一点。** `+=` 是「加上去」，把权重往「能把这个点分对」的方向调。

剩下那段 `for rnd in range(1, 100)`，就是「把上面这件事，重复做很多轮」。

**这就是全部的训练。** 没有别的了。什么深度学习、什么大模型，训练的核心都是这个「猜错就改一点，重复很多轮」，只是数据更多、模型更复杂。

## 一层一层加：改着玩

### 改成 2000 个点

把 `while len(data) < 200` 里的 `200` 改成 `2000`，还有后面两个 `100` 改成 `1000`。再跑一次，看准确率的爬升有什么不一样。

### 让两类点离得近一点

把造数据的部分，改成让两类点「贴得特别近」（把对角线附近的点都算上，让边界模糊）。你会看到，边界越模糊，学得越费劲，轮数越多。

### 看看权重学成了什么样

在代码最后加一行：

```python
print("学到的权重：w1=%.2f, w2=%.2f, b=%.2f" % (w1, w2, b))
```

再跑。学出来的 w1、w2 差不多是「一正一负」。这正好对应「对角线 x2 = x1」那条线（移项就是 x2 - x1 = 0，也就是 -x1 + x2 = 0，所以 w1 接近 -1，w2 接近 1）。

**这就是「机器自己找出了那条线」。** 它没被告诉线在哪，它自己「学」出来了。

## 卡住了看这里

**提示 `python: command not found` 或者「不是内部或外部命令」。** Python 没装好，或者装的时候没勾「Add to PATH」。重装一遍，勾上那个选项，装完重新开一个终端。

**提示 `IndentationError`。** Python 对缩进特别敏感，空格和 Tab 不能混用。你复制代码时如果缩进乱了，会报这个错。把代码里每行开头的空格删掉重打，或者直接整段复制。

**提示 `SyntaxError`。** 多半是中英文符号混了。Python 里冒号、括号、引号都要用英文的。检查有没有把 `:` 打成 `：`，把 `'` 打成 `'`。

**跑出来的准确率和资料里写的不一样。** 正常，随机数会影响。关键是趋势：从 50% 往上爬，最后到 100%。数字不完全一样没关系。

**想中途停掉。** 按 Ctrl 加 C。
