## 二、去人力之后，印记怎么办

这是"去人力"唯一的连带问题：学长署名验收取消了，印记谁签？

**改由系统验收通过后签发，价值来源从"真人署名"换成"证据自证"。**

印记页可查：你交了什么（链接/仓库/录屏）、逐条 ✓/✗ 记录、关键步骤截图、通过时间、编号。任何人可查可复核。

理由很实在：**对一个没名气的校园平台，"某个学长看过"是虚的，"证据摆在这里你自己看"是真的。** 而且免费用户也能拿印记——这才配得上"免费全能"。

社群答疑同样去人力：靠群友互助 + 学员主讲的复盘会，平台只做组织。**页面上会写清楚，承诺了做不到比不承诺更伤。**

## 四、三件新东西

**1. VIP 专属关卡**：硬规矩是**能力点守恒**——它考的能力，免费路径上必须有一关公开覆盖。卖的是更真实、有对手、复盘更细，不是新知识。Java 的三道：线上事故复盘室（给 GC 日志限时定位）、面试官对练（小搭追问 15 分钟）、需求方来了（小搭扮演产品改需求，你守接口设计）。

**2. 小搭 + 蓝图（68 档核心）**：把平台对你的了解摊开给你看。10 个字段，每个标**置信度 + 证据来源**（来自问卷第几题 / 第几站手感 / 哪次对话），能改、能锁、能撤销。小搭只会三件事：讲这个知识点（用你会的类比、跳过你会的）、给我找资料（只从课搭白名单挑）、重排下一步（输出限定的操作，编不出东西）。

**3. 38 档社群与直播激励**：开通即得永久群，停订转校友。直播激励堵了几个漏洞——到场率以报名人数为分母且到场 ≥15 人（防 3 人报名来 2 人拿奖），提前 72 小时交大纲审核，每学期每人 1 次，直播须沉淀成资料，每月总额上限 ¥600。

## 五、分支路线图（已批准：Java / 前端 / 产品）

三层：**方向页**（前景、典型一天、信息差、适合谁不适合谁）→ **6 阶段** → **24–30 关**（每关四拍 + 产出物 + 3 条常见卡点 + 挂资料）。

比探索线精细的量化标准：单关 1–2h → **3–6h**，总量 22h → **90–140h**，加每关 3 条卡点、每阶段验收关、小搭个性化。

**AI 助学层** 5 关、5 小时，插在阶段 2 之后。**只教用它把东西学懂，不教用它写代码**——平台不提供也不教 agentic coding（让它改项目、写单测那一套）。四关通用（怎么问才问得出有用的答案 / 让它把你讲懂 / 它说的不一定对 / 它能自动干到哪一步，最后一关只讲认知不实操）+ 每方向 1 关定制。

资料策略：**先画骨架再补资料，缺哪份写哪份**。

## 六、UI 升级怎么推进

每批 4 版，做同一个样本页（我的路线页，元件最全），你挑完再铺全站：

| 版 | 一句话 |
|---|---|
| A 贴纸工作室 | 现有卡通风加深，点击手感最爽，可能嫌幼稚 |
| B 编辑精度 | 去阴影只用线，信息最清楚，爽感弱 |
| C 暖色终端 | 暗色 + 等宽 + 日志流，极客感强，和品牌白底橙冲突最大 |
| **D 贴纸骨架 + 编辑排版（推荐）** | 有情绪的地方卡通，有信息的地方编辑排版 |

另附 18 条交互验收标准（按下反馈、乐观更新、撤销常驻、骨架屏、键盘全通、动效只允许出现在状态变化时）。装饰性动效全删。
