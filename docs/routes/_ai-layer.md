# AI 助学层（2.5 段）

所有分支路线共用，插在**阶段 2 之后**。约 5 小时。

> **定位（2026-09-21 修订）**：这一层教的是**用它把东西学懂**，不是用它写代码。
> 平台不提供、也不教 agentic coding（让它改项目、写单测、自动提交那一套）。
> 它是一个学习助手：**讲懂你不会的、帮你找资料、检查你是不是真懂了。**
> agent 那一块只讲**认知**（它是什么、能自动干到哪、边界在哪），不实操。

> **关于"AI"字眼**：本层教的就是 AI 怎么用，"AI"是**教学内容**（同"AI 应用开发"这类职业方向名），与"平台功能不得叫 AI"那条红线不冲突。

---

## 为什么插在阶段 2 之后

- 放在开头：他还不知道这个方向在干什么，问不出有价值的问题，只会得到一堆看不懂的答案。
- 放在结尾：前面 100 小时里本来可以少卡二十次，晚了。
- **阶段 2 之后**：他已经做出过一个能跑的小东西，知道自己卡在哪、哪些话听不懂，这时候才问得出好问题，也才判断得出它是不是在胡说。

## 通用四关

### 2.5-1 怎么问，才问得出有用的答案 · 1h

- **学**：它看不见你的屏幕，也不知道你学到哪了。你给的上下文决定答案质量
- **练**：同一个问题用三种问法问——
  ①「讲一下事务」
  ②「我在学事务，看不懂为什么加了注解还是不生效」
  ③「我在学事务，看不懂为什么加了注解还是不生效，我用的是 MySQL，代码是这样…」
  对比三个答案
- **创**：一份自己的**提问模板**：我学到哪了 + 我不懂的是哪一句 + 我已经试过什么 + 我想要什么深度
- **验**：下次提问，第一次答案就能直接用
- **卡点**：
  1. 答非所问 → 没说清你学到哪 → 先交代进度和已知
  2. 答案太浅或太深 → 没说要什么深度 → 明说"用大一能听懂的话讲"，或"直接讲原理"
  3. 它推荐了你根本没学过的东西 → 它不知道你的基础 → 在问题里说清你已经会什么

### 2.5-2 让它把你讲懂 · 1h

- **学**：一次听不懂不代表你笨。可以换说法、要例子、让它考你
- **练**：挑一个你没懂的概念，用四种方式追问——换种说法 / 举个生活里的例子 / 画一遍流程 / 出两道题考我——直到真懂
- **创**：一段"从不懂到懂"的对话记录 + 一句你自己的总结
- **验**：你能把它讲给同学听，同学听懂了
- **卡点**：
  1. 它一直重复同样的解释 → 你只说了"没懂" → 说清**哪一句**没懂
  2. 看着懂了，做题就废 → 输入不等于掌握 → 让它出题考你，别只看讲解
  3. 它越讲越远 → 话题发散 → 拉回来："回到刚才那个问题"

### 2.5-3 它说的不一定对 · 1h

- **学**：它会很自信地胡说。三种常见编法：编 API 和参数、编数据和来源、编书上没写的结论
- **练**：先让它回答三个你知道答案的问题，看它错在哪；再问一个你不懂的，用三种方法验证
- **创**：一份**「哪些话必须先核实」清单**——版本号、接口签名、数字、引用出处、涉及安全和责任的说法
- **验**：说得出三种验证方法：让它给证据 / 换个问法交叉验证 / 去源头核一眼
- **卡点**：
  1. 它给了个不存在的参数 → 编的 → 去官方文档核一眼再用
  2. 它引用了一份报告或一篇论文 → 可能是编的 → 让它给链接，打不开就是编的
  3. 它说"一般来说…"却给不出依据 → 在用模糊说法掩盖 → 追问一句"依据是什么"

### 2.5-4 它现在能自动干到哪一步 · 1h（只讲认知，不实操）

- **学**：知道就行——agent 是什么（自己拆任务、调工具、多轮执行），哪些事上它真的有用，边界在哪
- **练**：看两个真实例子（一个成了、一个翻车），说清为什么一个成、一个翻
- **创**：一份**「能交 / 不能交」清单**——
  能交：查资料、整理归纳、批量格式处理
  不能交：需要你负责和判断的事、涉及钱和权限的、要署你名的成果
- **验**：说得出三个它一定会翻车的场景
- **卡点**：
  1. 以为它能自己干完一切 → 过度信任 → 它不验证结果，验证是你的活
  2. 以为它什么都干不了 → 另一个极端 → 查资料整理这类确实比人快
  3. 分不清"能干"和"该干" → 能力不等于责任 → 要署你名的东西必须你自己过一遍

## 每阶段的「助学卡」（不占关卡号）

原"提速卡"改名。三栏：**这一阶段可以问它什么** / **问的时候给什么上下文** / **它答完你检查什么**。

| 阶段 | 可以问它 | 给什么上下文 | 你检查 |
|---|---|---|---|
| 1 环境 | 这个报错什么意思、这个选项该选哪个 | 你的系统版本、完整报错 | 版本号和路径是不是你的 |
| 2 数据 | 这个概念怎么理解、我这步做对没 | 你的表结构、你执行的语句 | 它给的语句里有没有删数据的操作 |
| 3 安全 | 为什么不能这么做、还有哪种情况我没考虑 | 你的实现方式 | 涉及安全的结论去源头核 |
| 4 性能 | 这个指标什么意思、可能的原因有哪几个 | 你的压测数据 | 它的猜测有没有数据支撑 |
| 5 工程 | 这个流程为什么是这样、我漏了什么 | 你的配置文件结构 | 密钥和端口 |
| 6 求职 | 面试官可能怎么追问、我哪里说得不清楚 | 你的项目 README | 每一个数字和细节是不是真的 |

## 红线

1. **不教用它写代码、改项目、写测试、自动提交。** 平台是学东西的地方，它在这里是学习助手。
2. 每一关都必须有**"它会错在哪"**——这是这层最值钱的部分。
3. **不神化、不恐吓**。不写"不会用就被淘汰"，也不写"它什么都能干"。
4. 不推荐具体付费工具的推广链接。
