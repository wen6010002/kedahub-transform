## 1. 付费结构变更（2026-09-21 定，推翻 REPORT.md 第四章）

### 1.1 新结构：全站只有三档

| 档 | 价格 | 一句话 |
|---|---|---|
| **免费** | ¥0 | 你来平台的目的，全部能实现 |
| **38 档** | ¥38 / 月 | 更快：有人一起走（永久社群）+ 加速配额 |
| **68 档** | ¥68 / 月 | 更好：专属学习搭子 + 蓝图 + 实时路线优化 |

**核心理念（写死，贯穿所有设计）**：免费版全都能实现，付费版实现得更快更好。付费**不解锁知识**，只解锁**速度、陪伴、体验**。

### 1.2 旧付费项处置表（REPORT.md 第四章作废部分）

| 旧项 | 处置 | 理由 |
|---|---|---|
| 系统验收 ¥9/关 | **取消售卖**，改三档配额：免费每周 3 次 / 38 每周 10 次 / 68 不限次 | 边际成本 ¥0.4，收 9 元与"免费全能"理念冲突 |
| 学长署名验收 ¥39/阶段 | **取消**（已确认）。印记改由系统验收通过后签发，附完整证据链 | 用户要求"尽可能去除人力"，学长复核 ¥12.5/次是最大人力项 |
| 项目组 ¥449/期 | **取消**（已确认）。能力拆给 38 档社群（复盘会/互评/直播）+ 68 档搭子 | 用户：项目组和陪跑占用大量人力 |
| 陪跑 ¥1299/月 | **取消**（已确认） | 同上 |
| 14 天免费试用 | **取消**。改为：68 档首月 ¥1 体验，一个 edu 邮箱一次 | 试用是给高价产品用的，两档订阅不需要 |
| 编号印记 | **保留**，但签发方式改（见 §1.4） | 这是"结果"的载体，不能丢 |

### 1.3 三处硬冲突及处理

**冲突一：订阅制 vs「不做订阅制」（REPORT §4.4 明确写过）**

旧论证成立：成长是阵发性的，停下来的月份继续扣钱最快毁信任。不能假装没写过，要用补丁解决：

- **随时停、一键续**，不做年卡、不默认勾选自动续费。
- **休整券**：每订阅满 1 个月发 1 张，可暂停 30 天不扣费（对应"期末停三周"）。**这是订阅制唯一的信任补丁，必须做。**
- **停订不掉内容**：路线、进度、印记全保留，只是加速层回到免费档。停订无惩罚感。
- 卖的是**加速与陪伴**，不是**内容**。用户停订时不会想"我学不到了"，只会想"没人陪了"——这是可接受的损失。

**冲突二：VIP 专属关卡 vs「免费全都能实现」**

> **能力点守恒原则（红线）**：任何一道 VIP 关卡考察的能力点，免费路径上必须存在至少一关公开覆盖同一能力点。VIP 关卡是同一能力的**另一种更真实、更爽的练法**，不是新知识。

对应多邻国：口语关卖的不是"只有付费才能学的语法"，是"更接近真实的对话体验"。

**冲突三：学习搭子 vs「对外不提 AI」**

- 对外命名：**「小搭 · 你的学习搭子」**。档位表写「专属学习搭子」，正文不出现「AI / 人工智能 / 大模型」。
- 用**"懂你"**传达智能，不用"AI"传达：文案走"它会记住你的情况""讲的时候跳过你已经会的"。
- 例外：设置页可有"由模型驱动"的技术说明（合规需要），不作为营销语言。
- 本文内部继续用"助手 / Agent"。

### 1.4 去人力的连锁处理（2026-09-21 确认）

用户要求「尽可能去除人力」。砍掉项目组与陪跑之后，还有三处藏着人力，必须一起处理，否则"去人力"是假的：

| 隐藏人力项 | 原方案 | 新方案 |
|---|---|---|
| **学长署名验收** | 真人助教复核，¥12.5/次 | **取消**。印记改由系统验收通过后签发（见下） |
| **群内答疑** | 平台派人答 | **群友互助 + 学员主讲复盘会**，平台只做组织 |
| **复盘会主讲** | 平台请学长 | **学员主讲**，用直播激励驱动（A5） |

**印记签发机制变更（重要，改了 REPORT 的核心论证）**

原论证：系统只判事实不判判断，"AI 说你通过了"说多了会把凭证说废，所以凭证必须由真人签发。

在无人力的前提下这条走不通。新方案的价值来源换一个：

> **从"真人署名"换成"证据自证"。** 印记页可查：交了什么（链接 / 仓库 / 录屏）、逐条 ✓/✗ 记录、关键步骤截图、通过时间、编号。任何人可查可复核。

理由：对一个没名气的校园平台，"某个学长看过"本身没有公信力；"证据摆在这你自己看"有。**而且免费用户也能拿印记——这才配得上"免费全能"。**

配套文案改动（覆盖 REPORT §4.7）：

- 原「系统验收的结论不构成凭证」→ **作废**
- 新：「印记附带完整验收证据，任何人可查可复核。它证明的是这份产出达到了这条路线设定的标准，不做就业承诺。」
- 社群互评保留为自愿活动，结果**不进印记**（平台不为互评背书）。

### 1.5 档位与周期（2026-09-21 确认）

月度为基础，季度 / 年度 = 月度的优惠包，**权益完全相同**，不加额外权益：

| 周期 | 38 档 | 折合/月 | 68 档 | 折合/月 | 折扣 |
|---|---|---|---|---|---|
| 月 | ¥38 | ¥38 | ¥68 | ¥68 | — |
| 季 | ¥98 | ¥32.7 | ¥178 | ¥59.3 | 86 / 87 折 |
| 年 | ¥328 | ¥27.3 | ¥588 | ¥49 | 72 折 |

规则：

- 折扣**不做得更狠**：季卡卖的是"省事"不是"便宜"，年卡 72 折是诚意上限。五折年卡会伤 MRR，也等于变相大额预收。
- 年卡单笔 ¥588，低于原合规红线（单笔 ≤ ¥1,299）。
- **年卡 7 天无理由全额退**；超过 7 天按已用月份 × 月度原价退剩余。
- 不默认勾选自动续费；到期前 3 天提醒一次。
- 页面必须有一句学生向的话：**「不确定就选月」**。不诱导超前消费。
- 现金收入按周期递延确认（季度/年度是预收，不当月收入）。

### A2 成本与盈亏边界（2026-09-21 重算：去人力后）

**去人力后的成本结构（用户确认"尽可能去除人力"）：**

| 原人力项 | 处置 |
|---|---|
| 学长署名验收（¥12.5/次） | 取消，印记改系统签发（§1.4） |
| 项目组带组学长 + 助教 | 取消 |
| 陪跑 1v1 | 取消 |
| 群内答疑 | 改群友互助，平台不出人力 |
| 每周资讯 | 编辑整理 ≈4 h/月（可自扛） |
| 复盘会主讲 | 学员主讲，平台只做组织 |

单价经济：

| 档 | 收入 | 模型 | 变动成本（社群 + 激励摊销） | 毛利 |
|---|---|---|---|---|
| 38 | ¥38 | ¥2 | ¥8 | ≈ ¥28（74%） |
| 68 | ¥68 | ¥8 | ¥18 | ≈ ¥42（62%） |

规模推演（按全部月付保守计，季度/年度只改善现金流不计入）：

| 免费用户 | 38 档 | 68 档 | MRR | 成本 | 净 |
|---|---|---|---|---|---|
| 500 | 12 | 7 | ¥932 | ¥560 | **+¥372 转正** |
| 1,200 | 30 | 18 | ¥2,364 | ¥796 | **+¥1,568** |
| 3,000 | 75 | 45 | ¥5,910 | ¥1,390 | +¥4,520 |
| 5,000 | 125 | 75 | ¥9,850 | ¥2,050 | +¥7,800 |

成本构成（1,200 人规模）：模型 ¥290 / 社群组织 ¥200 / 直播激励 ¥200（实际远低于上限）/ 固定摊销 ¥100。

**结论**：

1. **去人力后，盈亏平衡点从 3,000 免费用户降到约 500。** 这是本次改结构最大的收益——从"要熬 6 个月"变成"第一个月就能打平"。
2. 成本的 88% 是**模型与内容**，不是人。规模上去后边际成本几乎不动。
3. 直播激励月度总额上限 ¥600 保留（实际按 ¥200 计提）。
4. 产品上仍把人往 68 档推（毛利 ¥42 vs ¥28），但 38 档已不再是负担，可以放心做入口。
5. **唯一仍需盯的出血点**：免费用户的系统验收次数。若活跃率高于假设，模型成本会翻。设**全局月度模型预算上限**，触顶后免费档降到每周 1 次并在页面说明（付费档不受影响）。

### A3 VIP 专属关卡（仿多邻国口语关）

**性质定义**：体验型关卡，不是知识关卡。它提供三种免费版给不了的东西——

1. **更真实的场景**（真实事故日志、真实设计稿、真实需求方）
2. **有对手**（AI 扮演面试官 / 甲方 / 用户，会追问、会改需求）
3. **更细的复盘**（做完给一份个人能力诊断，指出你卡在哪一类问题上）

**每路线 3 道，挂在阶段 2、4、6 之后。** 示例：

| 路线 | VIP 关卡 | 覆盖能力点（免费路径必须有对应公开关） |
|---|---|---|
| Java | ① 线上事故复盘室：给一份 GC 日志 + 慢查询，限时定位 | = 阶段 4「性能优化」公开关 |
| Java | ② 面试官对练：小搭扮演面试官，针对你的项目追问 15 分钟 | = 阶段 6「项目讲解」公开关 |
| Java | ③ 需求方来了：小搭扮演产品反复改需求，你守住接口设计 | = 阶段 3「接口设计」公开关 |
| 前端 | ① 设计稿还原挑战 + 真机评审 | = 阶段 3「组件实现」 |
| 前端 | ② 性能急诊室：给一个卡顿页面，限时找出瓶颈 | = 阶段 5「性能优化」 |
| 前端 | ③ 甲方改稿：连改 3 版需求，你保住可用性 | = 阶段 2「交互实现」 |
| 产品 | ① 需求方对练：小搭扮演难缠业务方，你逼出真实需求 | = 阶段 2「需求澄清」 |
| 产品 | ② 数据急诊：给一份下跌的留存曲线，你说清原因 | = 阶段 4「数据分析」 |

**红线检查**（每道 VIP 关上线前必答）：这道题考的能力点，免费路径哪一关覆盖？答不出就不许上。

### A4 学习搭子与蓝图（68 档核心，本次最重要的新东西）

#### A4.1 蓝图是什么

**平台对你的了解，摊开给你看。** 不是黑箱推荐，是一张你能改的画像。这是"懂你"能被信任的唯一方式——用户看见它记了什么、凭什么记的、可以改。

10 个字段（原型阶段用 JSON 描述，**不落库**）：

| key | 名称 | 值域 | 主要来源 |
|---|---|---|---|
| `basis` | 现在会什么 | 技术栈清单 + 自评 | 问卷 Q6/Q7、验收记录 |
| `rhythm` | 节奏 | 每周小时、活跃时段、连续性 | 问卷 Q9、真实打卡时间 |
| `taste` | 手感 | 6 模块得分 1–3 | 探索路线 41 站打分 |
| `goal` | 目标 | 就业/实习/竞赛/考研/兴趣 | 问卷 Q12 |
| `deadline` | 时间点 | 大几、目标月份 | 问卷 Q10 |
| `stuck` | 常卡在哪 | 计数：装环境/看报错/不知下一步/做出来不知好不好 | 关卡求助记录、对话抽取 |
| `mastered` | 已掌握能力点 | 能力点 id 列表 | 验收通过记录 |
| `interest` | 方向权重 | 各方向 0–1 | 手感图谱 + 对话 |
| `style` | 讲解偏好 | 要类比 / 要代码 / 先讲用途 | 对话抽取 + 用户设置 |
| `taboo` | 不想学的 | 技术栈黑名单 | 用户手动（**仅用户可写**） |

每个字段的结构：

```
{ value, confidence(0-1), source:{type, ref, at}, history[], editedByUser, lockByUser }
```

- `source` 必须可见：写清"来自问卷第 9 题""来自第 12 站手感""来自 9-18 的对话"。**没有证据的了解不许写进蓝图。**
- `lockByUser`：用户锁定后系统不再自动改，只提示"系统观察到 X，要更新吗？"
- `taboo` 只有用户能写，系统永不推断。

#### A4.2 搭子的三种能力（对应页面三个动作）

| 动作 | 输入 | 输出 | 防幻觉约束 |
|---|---|---|---|
| **讲这个** | 当前知识点 + 蓝图 | 定制讲解：用他会的类比、跳过 `mastered` 里已有的、按 `goal` 讲"为什么学这个" | 不引用不存在的资料 |
| **给我找资料** | 蓝图 + 当前关 | 从**资料白名单**挑 1–3 份 + 一句"为什么是这份" | 必须给 `resourceId` |
| **重排下一步** | 蓝图 + 进度 | `RoutePatch` 序列 | 只能落在 §0 的 patch 枚举内 |

**Patch 枚举（在 REPORT 原有 5 种上扩展，仍是封闭集合）**：

```
skipStage / compressStage / insertStage / insertModule / swapProject   ← 原有
reorderStage / swapResource / setPace / markMastered                    ← 新增（搭子用）
```

从对话抽取的 `BlueprintPatch` 同样是封闭枚举：`setField / adjustConfidence / addEvidence / clearField`，`key` 必须是上表 10 个之一，值必须在值域内。Zod 校验，失败重试。

#### A4.3 助手页交互（关键爽点）

布局：**左对话流 / 右蓝图画布**，画布常驻可见。

- 对话中每抽取一条，画布对应卡片**边缘橙色脉冲 + "刚刚更新"角标 8 秒**，卡片下方出一行 `记下了：你更想做能给别人用的东西 · 撤销`。
- **撤销常驻**，不做确认弹窗。用户改了蓝图，卡片标「你改的」，系统后续有冲突证据时只在卡片上提示，不静默覆盖。
- 顶部一句话："平台现在对你的了解"，底部一句："这些了解决定：给你讲什么、推什么资料、下一步走哪关。"
- 三个常驻按钮：`讲这个知识点` / `给我找资料` / `按这个重排下一步`。

### B4 AI 助学层（公共模块，人人必走）

**定位（2026-09-21 修订，用户原话：「我并不打算让他们在我平台上写代码，只是一个学习助手就行」）**

> 这一层教的是**用它把东西学懂**，不是用它写代码。
> 平台不提供、也不教 agentic coding（让它改项目、写单测、自动提交那一套）。
> 它是学习助手：讲懂你不会的、帮你找资料、检查你是不是真懂了。
> agent 只讲**认知**（是什么、能自动干到哪、边界在哪），**不实操**。

用户仍要求"即使不走 AI 路线，也要涉猎基本的 AI agent 用法"——这一条由 2.5-4 单独一关承担，控制在 1 小时的认知课。

**5 关，约 5 小时，插在阶段 2 之后**（先有一点基础，才问得出好问题，也才判断得出它是不是在胡说）。编号不占阶段号，标记为「2.5 段」。

通用 4 关（写一次，所有路线共用）：

1. **怎么问，才问得出有用的答案**：提问模板 = 我学到哪了 + 我不懂哪一句 + 我试过什么 + 要多深
2. **让它把你讲懂**：换说法、要例子、画流程、让它出题考你
3. **它说的不一定对**：三种编法（编 API / 编数据 / 编结论）+ 三种验证方法
4. **它现在能自动干到哪一步**（认知，不实操）：agent 是什么、能交什么、不能交什么

方向定制第 5 关（每方向 1 关）：

- Java：用它讲透一个概念，并检查你是不是真懂
- 前端：用它读懂报错和别人的代码
- 产品：用它做调研，你来判断真假
- AI 应用开发：免修（本路线已覆盖）

每阶段另附一张**「助学卡」**（原"提速卡"改名，不占关卡号）：这一阶段可以问它什么 / 问的时候给什么上下文 / 它答完你检查什么。

**红线**：不教用它写代码、改项目、写测试、自动提交。每关必须有"它会错在哪"。

### C2 第一批四个方向

| 版 | 名称 | 视觉 | 动效特征 | "爽"从哪来 | 代价 |
|---|---|---|---|---|---|
| **A** | **贴纸工作室** | 现有卡通风加深：更粗描边（3px）、更硬投影、手绘 SVG 路径、纸纹噪点，小搭全程在场 | 回弹为主，`--ease-pop`；按下真的陷下去 |  tactile：每一次点击都有物理反馈 | 可爱度高，专业感低，高年级可能嫌幼稚 |
| **B** | **编辑精度** | 白底 + 单一强调色，卡片**去阴影只用 1px 线**，大字号层级，大量留白 | 克制到只剩位移 + 淡入 + 数字滚动 | 信息被整理得极清楚，一眼看懂 | 爽感弱，新生可能觉得像文档 |
| **C** | **暖色终端** | 深墨底 + 橙，等宽字体做编号与数据，卡片像面板，验收过程是**日志流** | 逐行打日志、光标闪烁 | 极客感，"系统在替我干活" | 与品牌白底橙冲突最大，暗色久读累 |
| **D（推荐）** | **贴纸骨架 + 编辑排版** | **分区用不同语言**：路线/成就/仪式 = 贴纸卡通风；阅读/资料/表格 = 编辑排版 | 统一四时长 + 两缓动，新增"即时反馈三件套" | 该可爱的地方可爱，该清楚的地方清楚 | 需要维护两套元件，规则要写死 |
