## 核心设计

- **交互语言「山径 · 印记」**：等高线山径（垭口=验收、云雾=未解锁、登顶=拿结果）+ 护照印章（8 枚印记拼合登顶纹章）+ Linear 式排印纪律。路线即连胜——走过的路永久点亮，不搞火焰焦虑。
- **隐藏式 Agent**：Vercel AI SDK `generateObject` + Zod，模板 + patch 架构（LLM 只输出对模板的操作指令，资源引用 enum 白名单），机制上消灭幻觉；Spring AI Alibaba Graph 承载验收四层漏斗。
- **商业逻辑**：免费给真价值（方向科普 + 专属路线 + 前两阶段），付费买结果服务（阶段验收 + 项目组 + 深度陪跑）。
