## 产品一句话

课搭还是课搭：首页还是**资料馆**，还是白底橙、宽幅信息流，还是「大学生成长社区」。

变的是资料馆里多长出来的两条腿——按**路线**串，按**信息差**挑。用户拿走的从「一堆文件」变成「一条走完的路 + 一份被认可的结果」。

## 三条主线

- **大一探索路线（免费）**：新生不该一上来选方向。8 站 × 约 2 小时，从终端黑窗口一路摸到脚本、Git、前端、服务器、数据库、AI、模型，每站产出一个能拿给室友看的小东西。每站结束打一次手感分，8 次打分生成**手感图谱**，据此推荐方向。方法论是**用行为数据代替自我描述**。
- **隐藏式 Agent**：模板保证下限，Agent 提供上限。模型只能对已验证的模板做增删改排序，patch 限定在枚举白名单内，资源引用走 Zod 校验——**机制上无法编造内容**。对外全程不出现「AI」字眼。
- **结果验收付费**：学习和探索全免费，收费只在**验收关**——一道独立的关卡，通过才算走完这个阶段。它卖两样东西：**AI 验收 ¥9/关**（免费用户每周送 1 次；无头浏览器把你交的东西真打开点一遍，回逐条 ✓/✗ + 截图证据 + 卡在哪），和**学长署名验收 ¥39/阶段**（给"做得怎么样"的判断 + 一枚编号印记）。关卡内容解锁后才显示，但**能力清单是公开的**——不是盲盒。

## 技术选型

**全部 TypeScript，一个代码库**，跑在课搭原有的 Next.js + BullMQ worker 上。Agent 用 Vercel AI SDK 的 `generateObject` + Zod 做结构化输出。不引入第二个运行时——生成一条路线是分钟级的低频任务，为它拆出一套 Java 服务，换来的是双倍的部署、监控、日志和依赖升级负担。
